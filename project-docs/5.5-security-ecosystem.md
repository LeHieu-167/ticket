# 5.5. Giải pháp Bảo mật và Xác thực Đa lớp (Security Ecosystem)

## (i) Đặt vấn đề
Hệ thống cần phân quyền chặt chẽ (RBAC) và cơ chế logout an toàn cho JWT (Stateless), tránh việc token bị lộ vẫn sử dụng được.

## (ii) Giải pháp: RBAC + Token Rotation + Redis Blacklist

### Chứng minh từ Codebase

**1. Phân quyền (RBAC):** `ticket-be/src/main/java/com/ticket/config/SecurityConfig.java`

```java
// Phân quyền theo URL và Method
.authorizeHttpRequests(auth -> auth
    .requestMatchers("/api/admin/**").hasRole("ADMIN")
    .requestMatchers("/api/organizer/**").hasRole("ORGANIZER")
    .anyRequest().authenticated()
)
```

**2. Secure Logout (Redis Blacklist):** `ticket-be/src/main/java/com/ticket/service/TokenBlacklistService.java`

```java
public void addToBlacklist(String token, long ttlInSeconds) {
    // Lưu token vào Redis với TTL bằng thời gian sống còn lại
    redisTemplate.opsForValue().set(BLACKLIST_KEY_PREFIX + token, "revoked", ttlInSeconds, TimeUnit.SECONDS);
}

public boolean isBlacklisted(String token) {
    return Boolean.TRUE.equals(redisTemplate.hasKey(BLACKLIST_KEY_PREFIX + token));
}
```

**3. Kiểm tra Blacklist mỗi request:** `ticket-be/src/main/java/com/ticket/security/JwtAuthenticationFilter.java`

```java
if (jwt != null && jwtUtils.validateJwtToken(jwt)) {
    // Chặn ngay nếu token nằm trong blacklist
    if (tokenBlacklistService.isBlacklisted(jwt)) {
        logger.warn("Token has been blacklisted (user logged out)");
        filterChain.doFilter(request, response);
        return;
    }
    // ...
}
```

**4. Token Rotation:** `ticket-be/src/main/java/com/ticket/service/RefreshTokenService.java`

```java
public String rotateRefreshToken(String oldRefreshToken, UUID userId) {
    // Xóa token cũ -> Cấp token mới (Security Best Practice)
    deleteRefreshToken(oldRefreshToken);
    return createRefreshToken(userId);
}
```

## (iii) Kết quả
Đảm bảo an toàn tuyệt đối cho phiên đăng nhập. Ngăn chặn Token Replay Attack và quản lý phiên người dùng hiệu quả mà không cần dùng Session truyền thống.
